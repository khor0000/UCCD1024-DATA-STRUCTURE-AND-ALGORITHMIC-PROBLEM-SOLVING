Tracing recursion output

Retrieval check • 20 seconds

From Lesson 24: what are the two things every exam recursion must have so it isn’t infinite?

reveal

A base case (an if that returns without calling itself) and a shrinking argument (every self-call passes something smaller).

The function

void p(int n) {
    if (n == 0) return;
    cout << n << " ";        // line A
    p(n - 1);
    cout << n << " ";        // line B
}

Step through p(3) the way the computer runs it

Press Next one line at a time. A new copy of p only appears when its call runs, and it disappears when it returns — so the box shows exactly what is alive right now. Each copy is drawn inside the one that called it, so you can see how deep you are. n is replaced by its real number, in red.

Read the nesting. When the box is four copies deep, that is four copies of p alive at once — p(3) holding p(2) holding p(1) holding p(0), each paused on its own p(…) line, each still holding its own n. The dashed paused copies do nothing until the copy inside them returns. Then they wake up, youngest first, and run the line below their call.

“How can n be 3 and 2 and 1 all at once?”

It can’t — and it isn’t one n. Every call to p makes a brand-new box for its own n, at its own address in memory. They share the name n in the source code, but at run time they are four separate boxes:

p(3)'s n   [ 3 ]   at address 0x61fe10
p(2)'s n   [ 2 ]   at address 0x61fde0
p(1)'s n   [ 1 ]   at address 0x61fdb0
p(0)'s n   [ 0 ]   at address 0x61fd80

This is the same as calling square(x) twice — each call gets its own x. Recursion just means the earlier calls have not finished yet, so all their boxes exist together. A for loop is the opposite: one box for i, written over every pass.

The same thing as a table

Once the freeze/unfreeze is clear, a table is faster to write in the exam. One row per action, a column for each copy’s own n; a greyed n is a paused copy.

Output: 3 2 1 1 2 3

The one step people get wrong. The last print is 3 — not 0, not 1 — because p(3)’s own n stayed 3 the entire time it sat paused. Line A and line B are the same text, but each reads the n of whichever copy is running.

Using the same p, how many numbers does p(2) print in total?

Right: 2 1 1 2. Two copies (p(2), p(1)), each printing once on the way down and once on the way back = 4.
Each copy runs line A (down) and line B (up). Two copies reach a print, so that is 2 × 2 = 4 numbers. The base case p(0) prints nothing.
