What is a pointer?

You already know a variable is a labelled box that holds a value. A pointer is nothing new on top of that — it's just a variable whose value happens to be someone else's locker number.

Picture a gym locker room. Every locker has a number on the door: locker 104, locker 105, and so on. Your gym bag sits inside locker 104. That number, 104, is the locker's address — a way to say "over there" without carrying the whole bag around.

Now imagine you write "my bag is in locker 104" on a sticky note and hand it to a friend. That sticky note is a pointer. It doesn't contain your bag — it contains the address of the locker that does.

In C++, every variable already lives at an address in memory — you just haven't had to look at it before now. A pointer is a variable whose job is to store one of those addresses.

Two boxes, two addresses. x lives at address 0x104 and holds 7. p lives at its own address, 0x200, and holds 0x104 — the address of x. The arrow is just a picture of "the value stored here is a locker number, and that locker number points back over there."

The two symbols

C++ gives you exactly two operators to move between "the box" and "the address of the box." Confusing these two is the single most common pointer mistake, so get the table below cold before moving on.

SymbolRead it asWhat it does
&x"address of x"Takes a plain variable, gives you its locker number.
*p"follow p"Takes a pointer (a locker number), gives you what's sitting in that locker.
 
int x = 7;
int *p = &x;   // p now holds the address of x — the arrow above

cout << x;      // 7            (the box itself)
cout << &x;     // 0x104        (x's address — some number like this)
cout << p;      // 0x104        (p's value IS x's address)
cout << *p;     // 7            (follow p, read what's there — same as x)
Notice * shows up twice with two different jobs: in int *p it's part of declaring a pointer ("p is a pointer to an int"). In *p on its own, it dereferences — follows the arrow. Same symbol, different moment. This will stop being confusing once you've used it a dozen times; it won't get a lesson of its own.

Primary source if you want another explanation of the same idea before the quiz: learncpp.com — Introduction to pointers.

Quick check — if int x = 7; int *p = &x;, what does *p give you?

Right. p holds x's address; *p follows that address and hands you what's sitting there — 7.
Not quite — that's what p alone (no star) would give you. *p means "follow the address stored in p," which lands you back at x's value, 7.

Second check — what expression would you write to get the address of x (not its value)?

Exactly — &x, "address of x."
Think about which symbol means "address of" versus "follow" — check the table above.

Anything about addresses or the two symbols still fuzzy? Ask your tutor before moving on — this is the one idea everything else in linked lists is built on.
