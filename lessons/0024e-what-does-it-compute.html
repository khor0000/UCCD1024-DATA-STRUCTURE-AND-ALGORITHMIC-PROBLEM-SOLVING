What does the function compute? (Q4c)

Retrieval check • 20 seconds

From Lesson 24: what is a “base case”, in one line?

reveal

The branch that ends the function without calling itself — it handles the input small enough to answer directly.

Q4c doesn’t want a trace of every value. It wants the purpose, in one sentence. Three steps — and below, each step run against a real function so you see how the sentence is built, not just handed to you.

The function

int m(int a[], int n) {
    if (n == 1) return a[0];
    int r = m(a, n - 1);
    if (a[n - 1] > r) return a[n - 1];
    return r;
}

Step 1 — find the base case, and read what it returns

Which line is the base case? The one that returns without calling m again. That is if (n == 1) return a[0];. (The line int r = m(a, n - 1); calls m, so it is not the base case.)

What is “the smallest input”? It is whatever makes that if true. The condition is n == 1, so the smallest input is an array with just 1 element. Not n = 0 — read the actual condition, it says 1.

What does it return for that input? a[0] — the only element.

So far: “for a 1-element array, the answer is that element.”

Step 2 — find the recursive step, and read the one thing it does with the result

The recursive step is int r = m(a, n - 1); — it asks m for the answer to the first n−1 elements and stores it in r.

Then it does one thing with r:

if (a[n - 1] > r) return a[n - 1];   // last element bigger? return it
return r;                            // otherwise keep r

In words: compare r (the answer for everything before the last element) with a[n-1] (the last element), and keep whichever is bigger. The operation is >, keep-the-bigger.

The step: “take the answer for the elements before the last one, compare it to the last one, keep the larger.”

Step 3 — say it in terms of the whole array

Seed (Step 1): a single element. Repeated action (Step 2): each level folds in one more element by keeping the bigger. Do that all the way up and you have compared every element and kept the biggest.

“It returns the largest (maximum) value among the first n elements of array a.”

Watch m(a, 3) actually run

The three steps tell you what to look for. This shows it happening, on a = {4, 9, 2} — so a[0] = 4, a[1] = 9, a[2] = 2. Same rules as the earlier walkthroughs: a copy appears when its call runs, and disappears when it returns — but this time each copy also hands a number back to the one that called it.

What the run showed. The deepest copy (m(a, 1)) returned the single element 4 — the seed. Every copy above it did the same one thing: compare its element to the number from below, keep the bigger. 4 → 9 → 9. The answer that comes out is the biggest element. That is why m computes the maximum.

The shortcut once you’ve done a few

The operation in the step usually names the whole function:

Step does…Function computes…
+ the elementthe sum
> keep biggerthe maximum
< keep smallerthe minimum
* nthe factorial
r + 1a count / a length
a cout“prints the elements in … order”

Drills — closed book, on paper

Drill 3 • describe

Run the three steps out loud, then write one sentence: what does f(n) compute for a positive integer n?

int f(int n) {
    if (n == 1) return 1;
    return n + f(n - 1);
}
reveal

Step 1: base case n == 1 → smallest input is n = 1, returns 1. Step 2: recursive step f(n - 1) gives the answer for everything below n; the one thing done with it is n + — add n. Step 3: adding each value from 1 up.
“It returns the sum 1 + 2 + 3 + … + n” (the sum of all integers from 1 to n).

Drill 4 • describe

Same three steps. What does c(a, n) compute?

int c(int a[], int n) {
    if (n == 0) return 0;
    int r = c(a, n - 1);
    if (a[n - 1] == 0) return r + 1;
    return r;
}
reveal

Step 1: base case n == 0 → smallest input is an empty array, returns 0. Step 2: r is the answer for the first n−1 elements; the one thing done — r + 1 when the last element is 0, otherwise pass r through unchanged. Step 3: add 1 for every element equal to 0.
“It returns how many of the first n elements of a are equal to 0” (it counts the zeros).
