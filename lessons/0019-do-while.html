Day 2 · Midterm Q1a — the third loop form

do-while

A do-while is a while loop with the condition moved to the bottom. Because the check happens after the body, the body always runs at least once — even when the condition was false from the very start.

That last sentence is the only thing Q1a tests here. Everything else you already know.

The shape

int i = 1;                    int i = 1;
while (i <= 3) {              do {
    cout << i << " ";             cout << i << " ";
    i++;                          i++;
}                             } while (i <= 3);
                                              ↑ semicolon. Required.

Both print 1 2 3. With these starting values they are identical, and that is exactly why the exam does not use these starting values.

Two syntax details that cost marks on paper:

  • The ; after while (…) is required. A while loop must never have one; a do-while must always have one. This is the reverse of the habit you already have.
  • The condition is written at the bottom, but it is still the same condition. Nothing is negated. It is not "repeat until" — it is still "repeat while".
Critical Exam Trap • The Semicolon After do-while

A do-while must end with a semicolon after its condition. A plain while loop must not have one. This is the reverse of the habit you already have, which is exactly why it is missed.

A stray ; on a normal while is worse than a typo — it makes the loop body empty, so the loop spins forever printing nothing.

Correct (earns marks)Incorrect (loses marks)
} while (i < 5);} while (i < 5)
while (i < 5) {while (i < 5); {

Where the two differ — the only case the exam cares about

Make the condition false before the loop is ever reached:

int i = 10;                   int i = 10;
while (i < 5) {               do {
    cout << i << " ";             cout << i << " ";
    i++;                          i++;
}                             } while (i < 5);

prints: nothing            prints: 10

The while prints nothing. The do-while prints 10. The body ran before anyone checked whether it should have.

Paying at the entrance versus paying at the exit.

A while loop is a turnstile at the door. You show your ticket before you get in. Invalid ticket, you never enter the room at all.

A do-while is a restaurant. You are seated, you eat, and the bill comes at the end. Even if you cannot pay, you already ate. The meal happened. Whether you come back tomorrow is what the check decides.

Quick check

A do-while loop's condition is false the very first time it is evaluated. How many times did the body run?

Correct. The condition sits at the bottom, so the body has already finished by the time it is read. A do-while body can never run fewer than once.
Where is the condition written — above the body or below it? Which one therefore happens first?

Type the exact output:
int k = 5;
do { cout << k; k++; } while (k < 3);

Yes. 5 < 3 was false from the start, but the body had already printed. This is the whole point of the form.
Read the loop bottom-up. Which happens first — the cout, or the while?
