What is a struct?

Right now, if you wanted to store one student's name and one student's mark, you'd use two separate variables: name and mark. That's fine for one student. A struct is just a way to staple several variables together into one labelled bundle, so they travel as a unit.

Picture an ID card. A blank ID card template has fields printed on it: Name, ID number, Photo. The template itself isn't anyone's card — it's the shape every card will follow. Once you print a real card for "Alex," you've filled in that shape with real values.

A struct is the blank template. A variable of that struct type is one filled-in card.

struct Student {
    string name;
    int    mark;
};

Student a;        // one filled-in card, blank for now
a.name = "Alex";  // fill in the Name field
a.mark = 88;      // fill in the Mark field

cout << a.name << " scored " << a.mark;   // Alex scored 88

The dot, a.name, means "on card a, read the Name field." That's the whole idea — no new symbol, no pointer involved yet, just a bundle of fields you reach into with a dot.

A struct can hold any type as a field — including another struct, an array, or (this is where it gets interesting, next lesson) a pointer. That last one is what makes a linked list possible at all.
