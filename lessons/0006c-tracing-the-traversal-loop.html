Tracing the traversal loop, step by step

Same list as Lesson 6b — box1 (0x500) → box2 (0x520) → box3 (0x540) → NULL. Now watch what cur actually holds, address by address, as this loop runs:

Node *cur = head;
while (cur != NULL) {
    cout << cur->item << " ";
    cur = cur->next;
}
// prints: 10 20 30

cur is its own pointer variable, living at its own address (0x700) — separate from every box it will ever point at, exactly like n1/n2/n3 were.

Iteration 1

Node *cur = head; copies head's value into cur. head holds 0x500, so now cur does too:

Loop check: is cur (0x500) equal to NULL? No → enter the loop.
cur->item: follow cur to box1, read item → prints 10.
cur = cur->next;: follow cur to box1, read box1's next field (0x520), store that into cur.

Quick check — after cur = cur->next; runs for the first time, what value does cur hold?

Right — cur = cur->next means "look up my current target's next field, and move there."
cur = cur->next reads the next field of whatever cur currently points at (box1), and overwrites cur's own value with it.

Loop check: cur is now NULL, so cur != NULL is false → the loop stops. No box for cur to point at — that's exactly the point of NULL: it's not the address of anything, it's the "nothing here" signal that ends the walk.

Output across all three iterations: 10 20 30, matching the comment in the code.

Second check — the loop runs exactly 3 times because there are 3 boxes. What specific value in cur is what actually stops it?

Exactly — cur becoming NULL (copied from box3's next) is what fails the while condition.
Look at the last diagram above — what does cur hold right before the loop check fails?
Going forward: any code involving pointers in this course will get this same treatment — a var-box (its own address, holding a value) with an arrow to whatever it currently points at, redrawn at each step where that value changes. If a diagram is ever missing for pointer-tracing code and it isn't clicking, ask for one.

If any single iteration's three steps (check → print → advance) still feels rushed, ask for it walked even slower before moving to the List container.
