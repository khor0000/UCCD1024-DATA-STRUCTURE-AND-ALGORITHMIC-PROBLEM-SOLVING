# UCCD1024 — Data Structure and Algorithmic Problem Solving

Study notes written as interactive micro-lessons for UTAR's UCCD1024 course.

## How to use

1. **Clone or download the whole repo** (not just individual files).  
   The lessons in `lessons/` load shared stylesheets and scripts from `assets/`, so both folders must sit side-by-side for the pages to render correctly.

2. Open any `.html` file in `lessons/` directly in your browser — no server needed.

## Folder structure

```
├── assets/          ← shared CSS and JS (required by every lesson)
│   ├── style.css
│   ├── quiz.js
│   ├── recwalk.js
│   └── stepper.js
└── lessons/         ← one HTML file per concept (open in browser)
    ├── 0001-what-is-a-pointer.html
    ├── 0002-structs.html
    └── ...
```
